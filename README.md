# 🎓 AttendAI – AI Powered Attendance Management System

AttendAI is an intelligent attendance management system built using **Streamlit**, **Supabase**, **Face Recognition**, and **Voice Recognition** technologies.  
The system helps teachers manage attendance automatically using AI-based student verification.


# 🚀 Features

## 👨‍🏫 Teacher Features
- Teacher Login & Authentication
- Create Subjects
- Manage Students
- View Attendance Records
- Share Subject Codes

## 👨‍🎓 Student Features
- Enroll in Subjects
- Face Registration
- Voice Registration
- Automatic Attendance Marking

## 🤖 AI Features
- Face Recognition Attendance
- Voice Recognition Attendance
- AI-based Student Verification
- Vector Embedding Storage using pgvector
